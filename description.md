Rather than building a toy ETL with clean data, I built an end-to-end Medallion pipeline designed to handle real-world ingestion flaws. I generated a synthetic e-commerce feed with ambiguous date formats, corrupt prices, and duplicate orders.

The pipeline is orchestrated by Airflow in Docker (Spark runs in local mode inside the Airflow containers), with a producer DAG appending a new batch of data every 2 minutes and the pipeline DAG ingesting it every 30. It standardizes the Bronze layer to Silver, isolates corrupt rows into a quarantine layer with diagnostic reason codes, and computes Gold marts. For serving, it uses a two-phase idempotent load into a PostgreSQL star schema via staging tables, and runs automated reconciliation tests comparing Spark SQL against Postgres SQL to guarantee data parity.
